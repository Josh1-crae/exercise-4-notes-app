# Noted — Exercise 4

A simple Next.js notes app demonstrating React event handling and form validation.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Try the app

1. Enter a non-empty Gmail address (for example, `student@gmail.com`).
2. Enter a password with at least 7 characters.
3. Sign in to open the notes workspace.
4. Create, search, edit, and delete notes. Notes are saved in this browser's local storage.
5. Choose **Log out** to return to the login page.

This is an educational front-end demo: login is validated in the browser and is not real authentication.
